# Seaborn Data Visualization

## Overview
This repository contains a structured collection of **Seaborn-based data visualization notebooks**
demonstrating key concepts of **Exploratory Data Analysis (EDA)** using Python.
The content is organized for **learning, practice, and professional evaluation**.

---

## Contents
The repository covers the following Seaborn visualizations:

- Line Plot  
- LM Plot (Linear Model Plot)  
- Histogram  
- Bar Plot  
- Scatter Plot  
- Count Plot  
- Box Plot  
- KDE Plot  
- Violin Plot  
- Swarm Plot  
- Cat Plot  
- Pair Plot  
- Heatmap  

Each notebook includes:
- Clear objective
- Well-structured code
- Proper markdown explanations
